# Recovery Aware — web (manual testing UI)

A small React app adapted from `../reference/recovery_aware_trainer_app.jsx`
for exercising the backend API in a browser. See the "Web app" section in
the repo root `README.md` for how to run it alongside the backend and what
it's for.

Quick reference:

```bash
npm install
cp .env.example .env
npm run dev
```
